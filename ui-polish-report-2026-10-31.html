UI polish with Hallmark

Branch ui/hallmark-polish, 31 October 2026. Website storefront, Customer, Vendor and Rider apps. Not pushed, not deployed.

What was done

Hallmark is a set of design rules for UI that looks made rather than generated. It has three depths: full redesign, restyle and polish. This pass is a polish: brand colours, fonts, layouts, routes and every handler, data call and test hook are unchanged. A full redesign rebuilds the composition of every screen and needs a file-by-file plan you approve, so it was not attempted unattended.

Within that, four kinds of fix:

  • Readability. Text and buttons that failed WCAG AA contrast now pass, mostly white text on bright green, red and amber in dark mode.
  • Machine-made tells. Shouted ALL-CAPS labels are now sentence case, emoji used as icons are now real icons, arrows glued to links are gone, and stray colours go through the theme.
  • Touch and access. 44–48dp tap targets, a visible keyboard focus ring on the website, screen-reader labels on icon buttons, and animations that respect the phone's reduce-motion setting.
  • Scenarios. Loading screens shaped like the content instead of a lone spinner, empty states that say what to do next, and error states with a retry.

Manager was left alone because its build is in progress (docs/manager-app-resume.md). The admin and vendor consoles on the website were also out of scope.

Decisions for you

  1. Tests pin the old shouty style. Vendor tests look for "HOW IT ADDS UP", "TODAY" and "STARTERS · 1", and Rider tests look for "NEEDED TO GET VERIFIED". Those strings were left as they were, because the agents may not edit tests. If you want sentence case everywhere, it is a small change plus the test updates.
  2. Customer app quantity stepper (+/−) is 32–38dp. Making it 48dp changes the menu row layout.
  3. Input borders are faint (1.3:1), below the 3:1 WCAG asks for field edges. Raising them changes how every form looks.
  4. "More info ›" on the website restaurant page does nothing (src/app/(customer)/restaurant/[slug]/page.tsx:160). Wire it up or remove it.
  5. The "Verified" badge on the customer app's rider card. Please confirm it reflects a real check.
  6. Missing behaviour, not built:
    • An app-wide offline banner in the customer app.
    • "Clear search" and "Clear filters" actions on empty search results (customer menu, vendor live board).
    • A Retry on vendor analytics.
  7. Layout items only a full redesign would settle:
    • A card inside a card on the groceries hero (website and app).
    • Order status shown three times on vendor order cards.
    • Accept is green in the popup but orange on order detail.
