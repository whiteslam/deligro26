Checkout page — three directions

Today the map sits open in the middle of checkout, so every scroll fights it and the order button is far from the address. In all three options the map becomes a separate, reusable pin picker that opens only when someone needs to move the pin. Same orange, same dark theme, same fields — only the structure changes.

A · One page, map on demand

Everything on a single scroll. The address is a compact card with a small map thumbnail; the full map opens only when you tap “Change pin”.

My pick: A for launch. It is the smallest change, keeps everything visible, and answers the main complaint, the map in the way. C is the natural next step once customers have saved addresses. In every option the map is one shared “pin picker” component, which is what makes it reusable on the profile and address screens too. Copy is English because the customer app is English only right now; every string is short, so Hindi can be switched back on later.
